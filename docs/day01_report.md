# День 1 — Загрузка и подготовка документов

Подготовлены восемь русскоязычных `.txt` по основам RAG. Загрузчик читает файлы в UTF-8 с BOM и без него, нормализует пробелы и удаляет пустые строки. Переносы между непустыми строками сохраняются для будущего чанкинга.

Каждый `Document` содержит `document_id`, `source_name` и очищенный `text`. В пределах одной папки идентификатором служит полное имя файла. `main.py` находит базу относительно собственного пути и печатает имена и длины документов.

## Проверки на Windows

Среда — Conda `rag_overall`, Python 3.12.16.

| Команда | Результат |
|---|---|
| `python -m pip check` | `No broken requirements found.` |
| `python main.py` | 8 документов, первый — 651 символ после очистки |
| `python -m pytest -q` | 7 тестов прошли |
| `python -m ruff check .` | `All checks passed!` |
| `python -m ruff format --check .` | Проверка форматирования прошла |

Чистый клон с GitHub проверяется после публикации коммита.
