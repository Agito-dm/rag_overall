# День 3 — Weaviate, Embeddings & Indexing

## Цель

Поднять векторную базу Weaviate, получить embeddings
для чанков и реализовать повторную индексацию без дублей.

## Среда разработки

- Windows 11
- Python 3.12.16
- Conda: rag_overall
- Docker Desktop 4.38.0
- Docker Engine 27.5.1
- Docker Compose 2.32.4
- Weaviate 1.39.17
- weaviate-client 4.23.1

Проект перенесён с ноутбука на стационарный ПК
через клонирование репозитория GitHub.

Проверка чистого клона коммита 6536ad1:
27 тестов прошли, Ruff без ошибок,
загружено 8 документов и создано 25 чанков.

## Реализация

Добавлены:

- `docker-compose.yml` — запуск Weaviate;
- `.env.example` — пример конфигурации;
- `config.py` — настройки приложения;
- `embedder.py` — получение и нормализация embeddings;
- `weaviate_store.py` — создание коллекции и индексация;
- `tests/test_embedder.py`;
- `tests/test_weaviate_store.py`.

В `main.py` добавлен режим `--index`.

## Embeddings

Модель: `gemini-embedding-001`.

Размерность: 768.

Для документов используется `RETRIEVAL_DOCUMENT`.

Выполняется L2-нормализация векторов.
Норма первого реального embedding составила 1.0.

Реализован настраиваемый интервал между запросами.
По умолчанию — 6 секунд.

## Weaviate

Коллекция: `KnowledgeChunk`.

Свойства объектов:

- document_id
- source_name
- chunk_id
- text

Используются собственные embeddings,
индекс HNSW и cosine distance.

Детерминированные UUID предотвращают дублирование.
Существующие неизменённые чанки пропускаются
до обращения к Gemini API.

## Возникшие проблемы и решения

1. Conda не была доступна в PowerShell.
   Настроено рабочее окружение на ПК.

2. Docker Engine первоначально не был доступен.
   Выполнен запуск Docker Desktop и обновление WSL.

3. Порт 8080 занят GeoServer.
   HTTP-порт Weaviate изменён на 8081.

4. ImportError при обновлении модуля weaviate_store.
   Синхронизированы функции модуля и их импорты.

5. AuthlibDeprecationWarning.
   Предупреждение сторонней зависимости,
   не нарушающее работу приложения.

## Ограничения

При изменении корпуса, embedding-модели
или параметров chunking необходимо перестроить индекс.

Автоматическая синхронизация базы
не входит в scope текущего учебного проекта.
