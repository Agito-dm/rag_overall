# План проекта rag_overall

План основан на оригинальном Telegram-ТЗ `RAG_roadmap_tg.md`. При финальной проверке сверяем проект с оригиналом.

| День | Работа | Что проверяем |
|---|---|---|
| 1 | Локальная база, загрузка и очистка текста | Загружаются 5–10 документов, CLI показывает имена и длины |
| 2 | Чанки, размер, overlap и метаданные | Длинные тексты режутся корректно, в примерах видны `document_id`, `source_name` и `chunk_id` |
| 3 | Weaviate, embeddings и индексация | Объекты и метаданные есть в базе, повторная индексация не создаёт дублей |
| 4 | Семантический поиск top-k | У результатов видны расстояние, источник и ID чанка. Проверены минимум пять вопросов |
| 5 | Генерация по контексту и ссылки на источники | Проверены 5–10 вопросов, сравниваются ответы с retrieval и без него |
| 6 | Порог релевантности и слабый контекст | Проверены вопросы с ответом и вне базы, оценён шум, записаны настройки |
| 7 | Единый CLI, демонстрация и аудит ТЗ | Минимум пять демо-вопросов, примеры ответов с источниками и запуск из чистого клона |

В финальном smoke test проверяем установку, наличие документов, запуск Weaviate, создание embeddings и индекса, тесты и работу CLI.
