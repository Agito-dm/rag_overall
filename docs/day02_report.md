# День 2 — Chunking документов

## Цель

Реализовать разбиение документов на чанки с перекрытием
и сохранением метаданных для последующей индексации в Weaviate.

## Реализация

Добавлен модуль `src/rag_overall/chunking.py` с функциями:

- `split_text()` — разбиение строки на чанки.
- `chunk_document()` — разбиение одного документа с метаданными.
- `chunk_documents()` — обработка списка документов.

Добавлена Pydantic-модель `Chunk` с полями:

- `document_id`
- `source_name`
- `chunk_id`
- `text`

Идентификаторы чанков формируются из имени документа
и порядкового номера фрагмента.

## Параметры

Основная конфигурация:

- chunk_size = 400 символов
- overlap = 80 символов
- step = 320 символов

Выбор параметров предварительный. Окончательно качество
chunking оценивается при semantic retrieval.

## Эксперименты

| Размер | Перекрытие | Количество чанков |
|---|---|---|
| 250 | 50 | 41 |
| 400 | 80 | 25 |
| 600 | 100 | 16 |

Все восемь документов успешно обрабатываются.

При параметрах 400/80 создано 25 чанков.
У каждого чанка сохраняются метаданные исходного документа.

## Ограничения

Алгоритм разбивает документы по фиксированному количеству
символов и может разрезать слова или предложения.

ID чанков стабильны для неизменённой конфигурации, но при
изменении текста или размера окна их содержимое может измениться.
В День 3 потребуется учитывать это при повторной индексации.
