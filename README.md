# rag_overall

Учебный RAG-проект на Python и Weaviate. На Дне 1 программа читает локальную базу знаний, очищает текст и выводит имя и длину каждого документа.

## Запуск Дня 1 в PowerShell

В активном окружении `rag_overall` с Python 3.12 выполни из корня репозитория:

    python -m pip install -e ".[dev]"
    python -m pip check
    python main.py
    python -m pytest -q
    python -m ruff check .
    python -m ruff format --check .

При запуске `main.py` ожидается строка `Загружено документов: 8`, затем по одной строке на файл. Длина указана в символах очищенного текста.

Файлы базы лежат в `knowledge_base/` и хранятся в Git. Формат — `.txt` в UTF-8. Пустые файлы пропускаются с предупреждением. Если файл не декодируется как UTF-8, программа сообщает его имя и завершает работу с ошибкой.

Docker понадобится с Дня 3 для запуска Weaviate.
