Подготовка текстовых документов

Кодировка UTF-8 позволяет хранить русские и английские тексты в одном файле. На Windows некоторые редакторы добавляют маркер BOM. Загрузчик может читать UTF-8 с таким маркером и без него через кодировку utf-8-sig. Усечённый или ошибочно сохранённый текст лучше поправить по имени исходного файла, которое указывает загрузчик.

Для обычной прозы достаточно заменить серии горизонтальных пробелов и табуляций одним пробелом, удалить пустые строки и привести окончания строк к LF. Границы непустых строк остаются доступными для последующей обработки. Подобная очистка подходит для этой текстовой базы. Для фрагментов Python, таблиц и других форматов, где пробелы несут смысл, потребуется иной способ подготовки.

В этой базе ID документа совпадает с именем файла вместе с расширением. В пределах одной папки имена уникальны, а повторное чтение сохраняет те же ID. Переименование файла меняет ID. Имя файла полезно хранить рядом с текстом уже на этапе загрузки, чтобы позднее передать его каждому чанку.
